# Requirements

## Functional requirements (what the system must DO)

- **FR1:** The system shall allow patients to check their queue number and status.
- **FR2:** The system shall display patients' estimated waiting time.
- **FR3:** The system shall calculate patient priority based on urgency and waiting time.
- **FR4:** The system shall assign patients to a suitable available queue.
- **FR5:** The system shall update the queue when a doctor becomes unavailable.

## Non-functional requirements (how the system must PERFORM)

- **NFR1:** The system shall allow only authorised users to access patient information.
- **NFR2:** The system shall display queue information within 5 seconds under normal testing conditions.
- **NFR3:** The system shall be easy for patients and staff to use.
