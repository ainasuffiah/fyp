# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a patient, I want to check my queue status, so that I know when my turn is.
-The system shows patient's queue number and position
-The system shows estimated waiting time 

2. As a staff, I want the system to arrange patient based on priority, so that urgent patient can be attended earlier.
-The system calculate patient's priority based on urgency 
-The system arrange patients based on their priority score

3. As a admin, I want manage queue, so that patients can be assigned to suitable queue.
-The system shows available doctor and queues
-The system updates queue when there is changes like doctor become unavailable or urgent cases comes up
