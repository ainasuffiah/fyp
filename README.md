# Web-Based Dynamic Queue Optimization System Using Priority Scheduling

This project aims to improve patient queue management by considering patient priority, waiting time and available doctors. The system will help assign patients to suitable queues and update queue information when conditions change.

## Problem statement
Managing patient queues in hospitals can be difficult, especially when there are many patients waiting. Normal queue systems may not consider factors like urgency and waiting time. Therefore, this project aims to develop a web-based queue system using weighted priority scheduling to help manage patient queues more efficiently.
